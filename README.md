# 🌳 의사결정 트리 빌더 (Decision Tree Builder)

브라우저에서 바로 사용할 수 있는 **인터랙티브 의사결정 트리(플로우차트) 편집 도구**입니다.
설치나 빌드 과정 없이 `index.html`을 열기만 하면 질문과 선택지를 노드/분기로 추가하면서
의사결정 트리를 시각적으로 만들고, 편집하고, 저장/공유할 수 있습니다.

## 주요 기능

- **노드 추가/편집** — 노드의 텍스트를 클릭하면 바로 수정할 수 있습니다.
- **분기 관리** — 오른쪽 사이드바에서 선택한 노드에 분기(예: "예"/"아니오")를 추가하거나
  이름을 바꾸고, 분기와 그 아래 하위 트리를 삭제할 수 있습니다.
- **자동 레이아웃** — 노드를 추가/삭제하면 트리 구조가 자동으로 정렬됩니다.
- **자식이 없는 노드는 "결과" 노드**로, 그 외에는 "질문" 노드로 자동 구분되어 색상이 달라집니다.
- **팬 & 줌** — 캔버스를 드래그해 이동하고, 마우스 휠이나 툴바 버튼으로 확대/축소할 수 있습니다.
- **자동 저장** — 브라우저 `localStorage`에 자동 저장되어 새로고침해도 작업 내용이 유지됩니다.
- **가져오기/내보내기**
  - JSON으로 내보내기 / 불러오기 — 트리 데이터를 파일로 저장하고 다시 불러올 수 있습니다.
  - SVG로 내보내기 — 트리를 이미지 파일로 저장해 문서나 슬라이드에 바로 붙여넣을 수 있습니다.
- **키보드 단축키**
  - `Insert` (맥 키보드는 `Tab`) — 선택한 노드에 분기를 추가합니다. `"예 / 아니오 / 보류"`처럼
    `/`로 구분해 입력하면 한 번에 여러 분기를 만들 수 있습니다.
  - `Delete` / `Backspace` — 선택한 노드와 그 아래 하위 트리를 삭제합니다.
- 별도 서버나 빌드 과정 없이 동작하는 순수 HTML/CSS/JavaScript 프로젝트입니다.

## 시작하기

브라우저에서 `index.html` 파일을 더블 클릭해서 열기만 하면 됩니다.

정적 서버를 통해 실행하고 싶다면:

```bash
npm start   # npx serve . 를 실행합니다
```

## 사용법

1. 처음 열면 예시 의사결정 트리가 표시됩니다. 노드의 텍스트를 클릭해 원하는 내용으로 바꿔보세요.
2. 노드를 클릭해 선택하면 오른쪽 사이드바에서 해당 노드의 분기를 확인/편집할 수 있습니다.
3. **"+ 분기 추가"** 버튼(또는 노드를 선택한 상태에서 `Insert`/`Tab` 키)으로 새로운 선택지(자식
   노드)를 만드세요. 분기 이름(예: "예", "아니오", 또는 커스텀 라벨)을 입력하면 새 질문 노드가
   자동으로 생성됩니다. `"예 / 아니오 / 보류"`처럼 `/`로 구분해 입력하면 한 번에 여러 분기가
   만들어집니다.
4. 자식이 없는 노드는 자동으로 "결과" 노드(초록색)로 표시됩니다 — 최종 결론이나 액션을 적으면 됩니다.
5. 더 이상 필요 없는 분기는 사이드바의 ✕ 버튼이나 **"이 노드와 하위 트리 삭제"**로 제거할 수 있습니다.
6. 완성한 트리는 **JSON 내보내기**로 저장해두었다가 **불러오기**로 다시 이어서 작업하거나,
   **SVG 내보내기**로 이미지를 뽑아 공유할 수 있습니다.

## 프로젝트 구조

```
index.html        # 앱 마크업
style.css         # 스타일 (라이트/다크 모드 지원)
treeModel.js       # DOM에 의존하지 않는 트리 데이터 모델 & 레이아웃 계산 로직
app.js             # 렌더링, 이벤트 처리, 팬/줌, 저장/내보내기 등 UI 로직
tests/             # treeModel.js에 대한 단위 테스트
```

`treeModel.js`는 브라우저(`<script>` 태그)와 Node.js(`require`) 양쪽에서 그대로 사용할 수
있도록 작성되어 있어, 핵심 로직(노드/분기 추가·삭제, 자동 레이아웃 계산)을 UI와 분리해
테스트할 수 있습니다.

## 테스트


## 데이터 형식

트리는 다음과 같은 간단한 JSON 구조로 저장됩니다.

```json
{
  "id": "n...",
  "text": "오늘 배포를 진행할까요?",
  "children": [
    { "id": "e...", "label": "예", "node": { "id": "n...", "text": "...", "children": [] } },
    { "id": "e...", "label": "아니오", "node": { "id": "n...", "text": "배포 보류", "children": [] } }
  ]
}
```
